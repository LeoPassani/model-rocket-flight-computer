# model-rocket-flight-computer
Original Flight Computer (ESP32, IMU, barometer, and MicroSD Logging) tested on original 3D-Printed Rocket designed in Solidworks. Trajectory (apogee height and time, burn time) calculated with MATLAB using rocket motor thrust curves and drag data generated in ANSYS Fluent.
The rocket, titled the Peter Trifin, houses an integrated tri-fin and motor mount, and has three printed components comprising of the main tube + fins, nosecone, and bulkhead.
